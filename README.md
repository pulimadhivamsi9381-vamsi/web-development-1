## Technologies

## Project Structure
- `01-Personal-Portfolio/` — profile, skills, projects and interactive contact form.
- `02-Digital-Library/` — book catalogue, title/author search, category filter and saved reading list.
- `03-Restaurant-Cafe/` — cafe story, menu, guest review and demo reservation form.
- `Screenshots/` — project preview images for the consolidated report.
- `Web-Development-ABL-Final-Report.pdf` — consolidated report.

## How to Run
Open any project folder and double-click `index.html`, or open it in a modern web browser. No server or installation is required.

## Note
These are front-end educational demonstrations. Contact and reservation forms display confirmation messages only; they do not connect to a backend server.
